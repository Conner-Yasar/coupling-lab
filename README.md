## 🧪 核心研究：耦合效应建模

### 背景

超表面的电磁响应不仅取决于单个单元结构，还受 **相邻单元间的电磁耦合** 影响。准确建模和量化这种耦合效应，对于设计高精度超表面至关重要。

### 方法

1. **采样策略**：对 `Atheta`（幅度）和 `Pphi`（相位）参数空间进行全网格周期采样，并在每个周期中心周围生成 `K=5` 组非周期五单元窗口 `[L2,L1,C,R1,R2]`
2. **扰动分层**：按邻居扰动强度分为 `low/medium/high` 三个层级
3. **CST 联合仿真**：Python 脚本驱动 CST Studio Suite 自动化求解
4. **耦合标签**：通过对比周期中心单元与非周期中心单元的 S 参数偏差，定义耦合强度标签
5. **结果分析**：曲线对比可视化、尖峰检测、复现性验证

### 关键数据

| 指标 | 数值 |
|------|------|
| 周期采样点数 | 11,011 |
| 非周期采样点数 | 55,055 |
| 采样参数对 | `Atheta`: 0~-45° / `Pphi`: 50~170° |
| 频段 | 6.0–24.0 GHz |
| 分析维度 | 周期 vs 非周期五单元对比 |

### 数据流

```
参数空间采样 → CST 周期求解 → 非周期五单元构建 → CST 五单元求解
→ S 参数导出 → 耦合标签计算 → 可视化分析 → 优化策略评估
```
